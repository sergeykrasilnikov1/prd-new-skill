# prd-new — рабочее досье для AI-агента

Навык сохраняет контекст работы в Markdown, чтобы другой чат мог прочитать
один документ и продолжить задачу без повторного пересказа.

Подходит для разработки, исследования, подготовки документов и других проектов.
Не привязан к языку программирования, платформе или предметной области.
PRD здесь означает рабочее досье: требования, текущее состояние, журнал и передачу
работы. Если нужен классический продуктовый PRD, навык сохраняет формат пользователя.

## Установка одной командой

Требуются Git и Node.js 22.20 или новее. Выполните из терминала:

```sh
npx skills add https://github.com/sergeykrasilnikov1/prd-new-skill --skill prd-new -g
```

Установщик предложит выбрать агента. Для установки сразу в Codex:

```sh
npx skills add https://github.com/sergeykrasilnikov1/prd-new-skill --skill prd-new -a codex -g -y
```

Без `-g` навык устанавливается для текущего проекта. Команды используют
[открытый установщик skills](https://github.com/vercel-labs/skills).
Другие агенты доступны, если поддерживаются установщиком и форматом Agent Skills;
их фактическое поведение зависит от возможностей конкретного клиента.

### Установка через Codex без терминала

Отправьте агенту с доступным skill-installer:

> Установи навык из https://github.com/sergeykrasilnikov1/prd-new-skill, папка skills/prd-new.

### Ручная установка

Скачайте репозиторий и скопируйте **всю** папку `skills/prd-new` в каталог навыков
вашего агента. Для Codex это обычно `~/.codex/skills/prd-new`; если задан
`CODEX_HOME`, используйте его подкаталог `skills/prd-new`.
Не перезаписывайте существующий навык без сохранения локальных изменений.
После установки начните следующий ход; если клиент не обновил список, откройте
новый чат. Шаблон и стандарт должны оставаться рядом с `SKILL.md`.

## Использование

Создать досье и обновлять его во время работы:

```text
$prd-new ПланЗапуска — подготовить план запуска проекта «Альфа».
Веди досье по ходу работы.
```

Указать корень документов, например папку хранилища Obsidian:

```text
Создай досье задачи «План запуска» для проекта «Альфа».
Корень документов: /путь/к/документам. Веди досье по ходу работы.
```

Или указать точную конечную папку:

```text
$prd-new ПланЗапуска "/путь/к/документам/Альфа" — подготовить план запуска.
Веди досье по ходу работы.
```

Продолжить в другом чате:

```text
Прочитай /путь/к/документам/Альфа/PRD_ПланЗапуска.md.
Используй prd-new и продолжи с раздела «Продолжить в новом чате».
```

Новый чат должен иметь доступ к файлу. Само наличие навыка не гарантирует,
что агент автоматически найдёт досье. Передайте путь или добавьте правило
чтения конкретного досье в инструкции проекта.

## Где хранятся документы

Приоритет: явный запрос → инструкции пользователя/проекта → `docs` в корне проекта.
В корне документов создаётся отдельная папка для каждого проекта:

```text
documents/
  Альфа/
    PRD_ПланЗапуска.md
    PRD_Исследование.md
  Бета/
    PRD_Редактура.md
```

Если указана конечная папка, имя проекта повторно не добавляется.
Существующие досье используются повторно; перенос документов автоматически
не выполняется. Если место или проект нельзя определить, агент уточняет их.

Чтобы один каталог использовался постоянно, сохраните в личных инструкциях
агента или `AGENTS.md` проекта:

```text
При использовании prd-new корень документов: /путь/к/документам.
Для каждого проекта создавай отдельную папку, для каждой задачи — своё досье.
```

## Что сохраняется

- Цель, требования, ограничения и критерии приёмки.
- Текущее состояние, препятствия и ближайший шаг в начале документа.
- Затронутые артефакты и ссылки на источники.
- Решения с причинами, неудачные подходы и причины отказа.
- Проверки: объект, способ или команда, среда и фактический результат.
- Актуальный TODO и инструкция следующему исполнителю.

При запросе **вести досье** агент обновляет его после существенных решений,
завершённых этапов, проверок и появления препятствий, а также перед финальным
ответом или передачей. Каждая операция инструмента отдельно не протоколируется.
Запрос только создать досье не разрешает выполнение самой задачи.

## Obsidian

Выберите корень документов или его родительскую папку как хранилище Obsidian.
Досье — обычные `.md` файлы, которые можно читать и редактировать напрямую.
MCP, запущенный Obsidian и платная синхронизация не требуются.

Для специальных ссылок, свойств и callouts можно дополнительно установить
[obsidian-markdown от kepano](https://github.com/kepano/obsidian-skills):

```sh
npx skills add https://github.com/kepano/obsidian-skills --skill obsidian-markdown -g
```

Это необязательный отдельный навык, он не включён в этот репозиторий.

## Состав

- [`SKILL.md`](skills/prd-new/SKILL.md) — создание, ведение и продолжение работы.
- [`PRD_TEMPLATE.md`](skills/prd-new/PRD_TEMPLATE.md) — шаблон досье.
- [`prd-standard.md`](skills/prd-new/prd-standard.md) — история, решения и закрытие.

## Ограничения

Досье сохраняет рабочий контекст, а не полную стенограмму чата. Оно полезно только
при актуальном содержании; предыдущие проверки не доказывают текущее состояние.
При аварийном завершении чата последние изменения могут не попасть в документ.
Секреты, ключи и лишние персональные данные в досье не записываются.
Не публикуйте реальные досье вместе с навыком без отдельной проверки содержимого.
